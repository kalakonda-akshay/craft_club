# Architecture Overview

## Tech Stack
- **Database:** Convex (Serverless DB, File Storage, Crons)
- **Runtime:** Convex V8 & Node Edge environments
- **Authentication:** Convex Auth (Custom Edge JWT & RBAC)
- **External Services:** Resend (Email Automation)

## Folder Structure
```text
/convex
  ├── _generated/            # Convex autogenerated schemas & API bounds
  ├── schema.ts              # Database schema definitions
  ├── auth.ts                # Convex Auth configuration
  ├── authHelpers.ts         # RBAC (SuperAdmin, Admin constraints)
  ├── logger.ts              # Centralized logging format
  ├── errors.ts              # Custom ConvexError boundaries
  ├── system.ts              # Health & Uptime endpoints
  ├── validators.ts          # Security layer for input sanitization
  ├── emailService.ts        # Native fetch wrapper for Resend
  ├── certificateGenerator.ts# Node runtime PDF & QR Code generator
  ├── certificates.ts        # Bulk workflows & management
  ├── dashboard.ts           # Central analytics aggregator
  └── crons.ts               # Background scheduled jobs
```

## Security Posture
- Inputs are strictly validated against regex before mutations.
- File uploads are validated via pre-signed URL limits.
- Errors never leak server stack-traces; they use typed `ConvexError` envelopes.
